# Blog API

REST API для блог платформы на Spring Boot

## Технологии
- Java 21
- Spring Boot
- Spring Data JPA
- PostgreSQL
- Lombok
- MapStruct
- Docker

## Функциональность
- CRUD для пользователей, постов, комментариев, тегов
- Связи между сущностями
- Пагинация и сортировка
- Валидация данных
- Обработка исключений
- Auditing (createdAt, updatedAt)

## Как запустить
1. Установи Docker
2. Клонируй репозиторий
3. Запусти: `docker-compose up --build`
4. API доступен на `http://localhost:8081`
